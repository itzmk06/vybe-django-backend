# 🛠️ Vybe Backend (Django)

This is the **backend service** for [Vybe](https://github.com/itzmk06/vybe-django-frontend) — a personalized movie and TV show recommendation platform.

Built using **Django**, this backend handles **user authentication** and **email verification**, leveraging Django’s secure built-in systems.

---

## 🚀 Features

- 🔐 User **Registration**, **Login**, and **Logout**
- ✅ **Email Verification** using Django's built-in email system
- 🛡️ Secure user management with Django's default `User` model
- 🔄 Scalable backend foundation for integration with any frontend

---

## ⚙️ Tech Stack

| Component       | Technology     |
|----------------|----------------|
| Language        | Python 3.x      |
| Framework       | Django 4.x      |
| Database        | SQLite (default) |
| Authentication  | Django Built-in |
| Email Service   | Django Email Backend (Console/SMTP) |
